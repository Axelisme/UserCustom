# Migrate to Orchestrate v179

## Purpose

Make TDD admission choose red-first work for its leverage, give uncertain tests a ticket-scoped
probe lifecycle, and refuse a lane whose final diff still carries a newly added provisional probe.

## Observable changes

- Admission records one specific red-first leverage reason for TDD or one specific reason for
  direct validation.
- Uncertain TDD probes live under `<existing-test-root>/_probe/<ticket-id>` through first green and are
  then promoted to the repository's ordinary/canonical test structure.
- `integration collect` returns a completed negative refusal with `code: unresolved_probe_paths`,
  deterministic `details.paths`, and a promote-or-delete repair when the final
  current-integration-to-lane diff adds tracked paths containing the exact `_probe` component.
- Pre-existing probe files that are only modified, and probe paths absent from the final tree, remain
  outside the refusal predicate; existing collection and lane predicates are unchanged.

## Report-version decision

`report_version` remains 2. This release changes admission guidance and collection preflight only;
it adds no report schema or telemetry migration.

## Active-task impact

A task admitted under v178 may continue its current Contract. A residual provisional probe is refused
at collection until the writer promotes useful coverage or deletes the path; no task state or
resolution command is added.

## Manual steps

None. Installation, setup, pinning, reload, and live HOME mutation remain user-owned and are not
part of this migration.

## Verification

Run the focused probe-collection Contract first, then the canonical probe-collection tests, complete
Orchestrate test selection, package integrity tests, release tests, Python compilation for changed
sources, and the task gate. Dogfood the lane-local v179 CLI against any residual probe before
promotion. Do not collect, accept, land, install, setup, pin, or push as part of this migration.

## Rollback

Restore the v178 package and manifest together. The v178 package remains compatible with existing
lane state; only red-first admission guidance, probe lifecycle guidance, and the residual collection
preflight are reverted.
