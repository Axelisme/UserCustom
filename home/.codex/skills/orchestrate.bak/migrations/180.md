# Migrate to Orchestrate v180

## Purpose

Correct the v179 uncertain-test lifecycle guidance so it remains compatible with repositories whose
ordinary test root is not fixed by the package.

## Documentation compatibility correction

- TDD probes live under `<existing-test-root>/_probe/<ticket-id>` through first green.
- Useful public-seam coverage is promoted into the repository's ordinary/canonical test structure.
- Repository-specific dogfood tests remain at their actual paths; this package introduces no universal
  test-root or test-framework convention.

## Preserved behavior and report contract

This is a documentation compatibility correction only. The collection predicate, production entrypoint,
observable refusal envelope, report schema, and usage envelope are unchanged from v179. `report_version`
remains 2; no telemetry or task-state migration is added.

## Active-task impact

Tasks already admitted under v179 retain their current Contract and lane state. The correction changes no
collection, promotion, resolution, or acceptance behavior.

## Manual steps

None. Installation, setup, pinning, reload, and live HOME mutation remain user-owned and are not part
of this migration.

## Verification

Run package integrity and documentation checks, the canonical test selection, Python compilation for
changed sources, and the task gate. Do not collect, accept, land, install, setup, pin, or push as part
of this migration.

## Rollback

Restore the v179 package and manifest together. The v179 package remains behavior-compatible; only the
repository-compatible lifecycle wording is reverted.
