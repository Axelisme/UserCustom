# Orchestrate v181 migration

Orchestrate v181 closes every agent acceptance lifecycle explicitly.

- `acceptance start` creates `refs/orchestrate/<task>/acceptance-open` at the exact detached
  acceptance snapshot. A second start, including the same SHA, refuses without replacing the
  worktree until Root records `acceptance result --verifier agent --outcome pass|fail`.
- Agent PASS/FAIL requires a clean detached acceptance HEAD equal to the open ref and closes that
  ref in the same Git transaction as the `accepted` authority transition. User PASS/FAIL remains
  independent and changes only `user-accepted`.
- Status projects the open SHA and actionable result warning. Normal task removal refuses an open
  gate; authorized `--abandon` removes it with the task inventory. Older accepted snapshots remain
  landable while a newer gate is open.
- Reports are version 3. They separately count starts, agent PASS/FAIL, user PASS/FAIL, superseded
  and unresolved starts, verdict coverage, and agent pass rate. They replay append-only telemetry,
  include exact agent spans, and warn on unresolved, orphan, and legacy-ambiguous history without
  rewriting the raw event artifact.
- Upgraded tasks recover only the latest unmatched legacy start whose subject equals the current
  acceptance worktree HEAD; older unmatched history remains report evidence and does not block new
  work.

No installation, pinning, live-HOME mutation, push, or remote publication is performed by this
migration.
