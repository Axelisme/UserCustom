# Orchestrate v182 migration

Orchestrate v182 carries the acceptance-gate corrections forward without rewriting v181.

- `acceptance-open` is lifecycle authority only when it is an exact direct commit ref. Symbolic
  and non-commit gate state refuses before any authority, worktree, or telemetry mutation.
- Agent acceptance updates `accepted` and closes `acceptance-open` in a non-dereferencing Git
  transaction after the exact gate and detached acceptance HEAD have been validated.
- Reports retain independent `acceptance-user` markers but do not emit user acceptance spans;
  agent spans, counts, rates, coverage, and append-only telemetry replay remain intact.
- Legacy recovery considers only the final unmatched acceptance start and recovers it only when
  its subject equals the current acceptance worktree HEAD. Older unmatched history remains report
  evidence and does not block prospective work.
- The verifiable v181 migration and manifest remain unchanged; this exact-next v182 package adds
  the corrected source, migration, and manifest.

No installation, pinning, live-HOME mutation, push, or remote publication is performed by this
migration.
