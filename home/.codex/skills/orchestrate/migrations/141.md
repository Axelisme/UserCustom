## Active-task impact

None. No command that touches repository state, task worktrees, refs, acceptance, landing, or
telemetry changed. Task records, pins, and reports are unaffected, and no conversion is performed.
An active task that dispatched one of the removed profiles must pick a surviving profile, because
the profile files themselves are gone from the fleet, not merely unbound.

## Rollback

If any verification fails, stop before the next authority boundary. Before setup, reject the source
and repair it through the normal admitted lane. After setup, repair forward to a verified v141
package while preserving user data. Do not reseal a historical manifest to make a package look
healthy, and do not restore the removed profiles by hand without republishing.
