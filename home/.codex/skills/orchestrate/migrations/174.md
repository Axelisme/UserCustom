# Migrate to Orchestrate v174

## Purpose

Replace hand-maintained correction timing and rework bookkeeping with Git-derived facts while
keeping the worker identity attestation and the remaining human diagnosis obligation.

## Observable changes

- The `timing pause` and `timing resume` commands, their telemetry transitions, and auto-resume
  plumbing are removed. An old timing invocation is an unknown command; event gaps are not
  interpreted.
- New reports use `report_version: 2`. They retain wall-clock `wall_seconds` and span
  `elapsed_seconds`, but emit neither `recorded_seconds` nor `paused_seconds`; recorded-time rates
  and pause spans are gone. The version increments because the report schema and its measured
  semantics changed, rather than merely adding an optional field.
- `status --task-id <task>` emits a lexically sorted `collect_rounds` mapping from each collected
  `Ticket:` trailer to its non-negative production-bearing round count. A round is counted when its
  newly collected lane range contains a commit not marked `Origin: contract`; contract-only rounds
  are omitted, and no rounds emits `{}`.
- TDD workers report the exact red command/reason at the Contract stop and validation
  commands/results at lane-ready. Root reads SHA, tree, base, protected paths, and Contract commits
  from `lane check`; direct workers likewise leave those Git facts to the check. The worker-side
  cwd, Git identity, branch, and clean-state attestation remains required.
- S3 names `status.collect_rounds[<ticket>]`; before another production correction at a derived
  value of three or more, Root still writes what the preceding diagnoses missed.

## Active-task impact

Report consumers must accept report version 2, use wall-clock fields only, and stop expecting
pause/resume-derived keys or rates. Root can read collected production rounds directly from status
instead of maintaining a matching counter. Contract-only collections remain excluded from the
measured value.

## Manual steps

Update any report consumer that depended on `recorded_seconds`, `paused_seconds`, pause spans, or
recorded-time rates. Replace hand-counted correction-round notes with `status --task-id`'s
`collect_rounds` projection, retaining only the required third-round diagnosis prose.

## Verification

Run `orchestrate.py doctor` and the canonical test suite. Run the focused machine-facts tests to
verify timing-command rejection, wall-clock-only reports, empty and sorted collect-round
projections, and exclusion of an `Origin: contract`-only collection.

## Rollback

Restore the v173 package and manifest together. Consumers that only read wall-clock fields remain
compatible with v173, but v174 report consumers must not rely on the retired timing fields after
rollback.
