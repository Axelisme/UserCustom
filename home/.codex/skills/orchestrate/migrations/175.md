# Migrate to Orchestrate v175

## Purpose

Correct the collect-round boundary using only facts Git can prove, and keep worker terminal reports
focused on identity and validation evidence while Root reads lane facts from `lane check`.

## Observable changes

- `status --task-id <task>` continues to emit the same `collect_rounds` mapping and field name.
  A newly collected range is excluded only when Git proves every commit is Contract-originated,
  changes only an earlier `Immutable:` path, or carries no first-parent content change. Ordinary
  production commits retain their existing counts.
- A Contract commit followed by an `--amend-frozen` Contract-path amendment remains excluded. A
  sync merge whose first-parent tree carries already-integrated work with no new content change
  remains excluded.
- S3 now claims only these Git-provable exclusions. Backlog, decision blocking, and rollout
  correction remain human classifications and are not inferred by status; the third-production-
  correction diagnosis obligation remains.
- TDD workers still report the exact red command/reason at the Contract stop and validation
  commands/results at lane-ready. Direct workers still report their validation commands/results.
  Neither terminal report restates changed or protected paths; worker-side identity attestation
  remains, and Root reads SHA, tree, base, protected paths, and Contract commits from `lane check`.

## Report-version decision

`report_version` remains 2. This release changes collect-round classification and dispatch prose,
not the report object schema or its wall-clock measurement contract established by v174.

## Active-task impact

No report consumer migration is required beyond v174. Root should use the unchanged
`status.collect_rounds` field for the measured value and retain human diagnosis for classifications
that Git cannot prove.

## Manual steps

None. Keep the existing worker identity attestation and red/validation evidence in terminal reports;
let `lane check` supply the Git facts.

## Verification

Run the focused machine-facts Contract tests, the canonical test suite, `orchestrate.py doctor`, and
`orchestrate.py doctor diff 174 175`. Confirm both Contract-amendment and sync-carriage regressions
remain excluded while ordinary production counts remain unchanged.

## Rollback

Restore the v174 package and manifest together. The v174 report schema remains compatible; only the
v175 Git-derived collect-round boundary and dispatch/S3 wording are reverted.
